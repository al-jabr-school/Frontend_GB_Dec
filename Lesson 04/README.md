# Lesson 04

- **:nth-child(5)**: birga kelgan elementlardan 5-elementni tanlash (masalan: li, td). 
- **:nth-child(odd)**: birga kelgan elementlarda faqat toq sondagi elementni tanlash (masalan: 1, 3, 5, 7). 
- **:nth-child(even)**: birga kelgan elementlardan faqat juft sondagi elementni tanlash (masalan: 2, 4, 6, 8).

- **:nth-of-type(1)**: dokument ichida ishlatilgan elementlardan 1-elementni tanlash (masalan: table, ul).
